Privacy Policy

Last updated: 2026-09-25

This application is a personal, single-user automation tool built and operated solely by Vaibhav Gupta for his own use. It is not offered as a public or commercial service, and no other individuals' data is processed by it.

What data is accessed

The application uses the Gmail API (read, send, and modify scopes) to access the owner's own personal Gmail accounts, strictly to:

  • Read and summarize incoming email for a personal daily digest.
  • Read specific account-statement emails (e.g. CDSL/NSDL statements) to extract the owner's own investment holdings for a personal portfolio summary.
  • Send messages on the owner's behalf (e.g. relaying a summary).

How data is used and stored

All data retrieved from Gmail is processed locally on the owner's own machine and is never transmitted to any third party, sold, or used for advertising. Processed summaries may be delivered to the owner via a personal messaging channel (WhatsApp) that the owner controls. OAuth tokens are stored locally on the owner's machine and are never shared.

Data retention

Extracted data (e.g. holdings summaries) is retained locally only for as long as needed to generate the next personal report and is not retained indefinitely in any external system.

Third parties

No data accessed via this application is shared with any third party.

Contact

For any question about this application or its data practices, contact the owner at the email associated with this GitHub account.
